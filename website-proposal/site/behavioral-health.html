Common billing errors

What gets behavioral health claims denied.

The session time isn’t in the note

Without the time, the code can’t be supported. In a federal audit, 128 of 216 sampled psychotherapy days didn’t meet Medicare requirements, and the estimate was $580 million in improper payments in one year.

How to avoid itWrite the session time in every psychotherapy note.

The wrong time-based code

A 50-minute session is a 90834, not a 90837. Rounding up to the next code isn’t allowed.

How to avoid itChoose the code from the documented minutes.

Evaluation and psychotherapy on the same day

90791 and a psychotherapy code on the same day by the same provider are not paid together.

How to avoid itBill the evaluation on its own day, or only the service that was done.

Crisis billed with regular psychotherapy

90839 can’t be billed the same day with 90832–90838 or with 90785.

How to avoid itUse the crisis code alone for that encounter.

Counselors and family therapists not enrolled

They can bill Medicare since 2024, but only after enrolling.

How to avoid itEnroll every provider before they see Medicare patients.

Codes we bill every day

We know the rule behind each code.

Which ones are billed by the minute, which only once per session, and which can’t go on the same claim.

  • 90791Per sessionDiagnostic evaluation
  • 90832By timePsychotherapy, 16 to 37 minutes
  • 90834By timePsychotherapy, 38 to 52 minutes
  • 90837By timePsychotherapy, 53 minutes or more
  • 90846 · 90847By timeFamily psychotherapy, without and with the patient
  • 90853Per sessionGroup psychotherapy
  • 90839 · 90840By timePsychotherapy for crisis (first 60 minutes, each additional 30)
  • 90785Per sessionInteractive complexity, added to another code
Before a claim goes out

A quick check for every psychology & behavioral health claim.

  • Session time in the note
  • The code matches the minutes
  • No 90791 with psychotherapy the same day
  • No crisis code with regular psychotherapy
  • Every provider enrolled with Medicare
